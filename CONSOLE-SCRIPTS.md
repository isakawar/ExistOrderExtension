# Запуск smoke-тесту без встановлення розширення

Для тих, хто не хоче встановлювати Chrome-розширення — той самий функціонал
доступний як один файл, який можна вставити прямо в консоль браузера. Це та
сама бізнес-логіка, що й у розширенні (`platforms/ua/*.js` / `platforms/pl/*.js`),
просто зібрана в один файл без залежності від Chrome Extension API.

Файли:

- [`console-scripts/ua-smoke-console.js`](./console-scripts/ua-smoke-console.js) — для UA (`staging.exist.ua`)
- [`console-scripts/pl-smoke-console.js`](./console-scripts/pl-smoke-console.js) — для PL (`stagingpl.exist.ua`)

## Як запустити

1. Відкрити потрібний сайт (UA або PL) і авторизуватись своїм звичайним акаунтом.
2. Відкрити DevTools: `F12` або `Cmd+Option+I` (Mac) / `Ctrl+Shift+I` (Windows).
3. Перейти на вкладку **Console**.
4. Відкрити потрібний файл (`ua-smoke-console.js` або `pl-smoke-console.js`) у
   будь-якому текстовому редакторі, скопіювати **весь вміст**.
5. Знайти на самому початку файлу блок:

   ```js
   const CONFIG_INPUT = {
     PHONE: '+380666746222',
     COUNT: 10,
     DELIVERIES: [ ... ],
     PAYMENTS: [ ... ],
   };
   ```

   і відредагувати прямо у скопійованому тексті (в редакторі, до вставки в
   консоль — так простіше, ніж редагувати вже в консолі):
   - `PHONE` — тестовий номер телефону.
   - `COUNT` — скільки замовлень створити.
   - `DELIVERIES` / `PAYMENTS` — видалити (або закоментувати `//`) рядки з
     методами, які не потрібно тестувати цього разу.
   - (тільки UA) `ONE_CLICK_ENABLED: true` — щоб додати тестування "Замовлення в 1 клік".

6. Вставити весь відредагований текст у консоль і натиснути **Enter**.
7. Спостерігати за логами прямо в консолі — кожне замовлення показує статус
   (⏳/✅/❌), а в кінці друкується підсумок (Total/Passed/Failed).

## Корисно знати

- **Зупинити на середині:** ввести в консолі `window.__uaSmokeStop = true`
  (для PL — `window.__plSmokeStop = true`). Поточне замовлення довершиться,
  наступні вже не почнуться.
- **Скопіювати summary:** після завершення в консолі виконати
  `copy(window.__uaSmokeSummary)` (або `__plSmokeSummary` для PL) — текст
  потрапить у буфер обміну, можна вставити в Slack/Jira.
- Скрипт **не має власної авторизації** — використовує cookies поточної
  сесії браузера, нічого не зберігає.
- Кожен запуск скрипта в консолі — одноразовий; щоб запустити ще раз (навіть з
  тими самими параметрами), потрібно знову вставити весь файл і натиснути Enter.
- Якщо просто хочете постійний UI без копіювання коду щоразу — простіше
  встановити розширення один раз, дивіться [INSTALL.md](./INSTALL.md).

## PL: які способи доставки підтримуються

Скрипт (як і розширення) **не підтримує** 2 з 9 варіантів доставки на PL —
"Почтомат или Пункт выдачи" та "В отделение или почтомат Nova Post". Обидва
вимагають вибору конкретного локера/точки видачі через окремий API, якого
немає в цій версії — без нього сервер повертає помилку
`500 KeyError('delivery_service_id')`. Деталі — в [README.md](./README.md#pl-deliverypayment-коди).
