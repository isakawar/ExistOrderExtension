# Встановлення Chrome-розширення "Exist Order Creator"

Інструкція для тих, хто хоче встановити повноцінне розширення (рекомендовано —
зручний UI, live-прогрес, історія результатів). Якщо просто хочете швидко
запустити тест без встановлення — дивіться [CONSOLE-SCRIPTS.md](./CONSOLE-SCRIPTS.md).

## 1. Скачати код з GitHub

**Варіант A — без git (простіше):**

1. Відкрити репозиторій на GitHub.
2. Кнопка **Code** → **Download ZIP**.
3. Розпакувати архів у будь-яку зручну папку (наприклад, `~/Documents/exist-order-creator`).

**Варіант B — через git (якщо звично):**

```bash
git clone <URL репозиторію>
```

## 2. Встановити розширення в Chrome

1. Відкрити `chrome://extensions` в адресному рядку.
2. Увімкнути перемикач **Developer mode** (Режим розробника) у правому верхньому куті.
3. Натиснути **Load unpacked** (Завантажити розпаковане розширення).
4. Обрати папку проєкту (ту, де лежить файл `manifest.json` — це коренева папка
   репозиторію, не вкладена `popup/` чи `platforms/`).
5. Іконка розширення з'явиться в списку і на панелі інструментів Chrome (можна
   закріпити, натиснувши на іконку пазла 🧩 в тулбарі → значок-кнопку поруч з
   "Exist Order Creator").

## 3. Оновлення до нової версії

Коли в репозиторії з'являються зміни:

1. Скачати новий ZIP (або `git pull`, якщо клонували через git) і замінити стару папку.
2. Відкрити `chrome://extensions`.
3. Натиснути кнопку **перезавантаження** (⟳) на картці розширення.

Без цього кроку Chrome продовжує використовувати стару версію коду.

## 4. Як користуватись

1. Відкрити сайт (UA — `staging.exist.ua`, PL — `stagingpl.exist.ua`), авторизуватись.
2. Відкрити popup розширення.
3. Платформа визначається автоматично за сайтом; якщо обрано не ту платформу —
   з'явиться попередження і кнопка запуску буде заблокована.
4. Вказати телефон, кількість замовлень, способи доставки/оплати.
5. **Запустити Smoke Test** → підтвердити в діалозі.
6. Дочекатись завершення, за потреби скопіювати summary кнопкою **Copy Summary**.

Детальніше про архітектуру та бізнес-логіку — у [README.md](./README.md).
